# カメラプロファイルとカメラデータ

対象はRawTherapee 5.13のコミット`1924179107995b01b73cdc7f4fe91e44fc8227a7`からOpenRoom 0.7.9へ同梱したデータです。[profile-notices.json](profile-notices.json)に全ファイルのSHA-256、埋め込み著作権表示と根拠の区分を記録しています。実アプリのファイルと固定コミットのファイルが一致することを確認しました。

## 同梱範囲

| 種類 | 件数 |
| --- | ---: |
| DCPカメラプロファイル | 161 |
| 入力ICCプロファイル | 26 |
| 入力ICMプロファイル | 9 |
| 出力ICCプロファイル | 22 |
| 合計 | 218 |

以前の目録はICM 9件を含んでいませんでした。現在の検査は拡張子だけで対象を選ばず、同梱ディレクトリの全ファイルを照合します。プロファイル以外の`camconst.json`と`dcpprofiles/camera_model_aliases.json`も記録しています。

## ファイル内の表示

| 表示 | 件数 | 根拠の扱い |
| --- | ---: | --- |
| CC0を明記 | 29 | 明示されたCC0表示を保持。公式の[CC0本文](native/RawTherapee-5.13/profile-CC0-1.0.txt)を収録 |
| public domainを明記 | 46 | 明示されたpublic domain表示を保持 |
| No copyrightを明記 | 2 | 明示された著作権を主張しない表示を保持 |
| Maciej Dworak名のみ | 67 | 適用ライセンスの確認が必要 |
| 著作権タグなし | 35 | 適用ライセンスの確認が必要 |
| `(c) Nobody` | 26 | 権利放棄の条件が明確でないため確認が必要 |
| `Copyright_free` | 9 | ICMにこの表示はあるが、適用条件の確認が必要 |
| 作成者名などの表示のみ | 4 | 適用ライセンスの確認が必要 |

77件には明示表示があります。残る141件と上記JSON 2件は、個別の適用条件を確認する対象として残しています。表示の有無だけで、配布禁止とも許諾済みとも判断していません。

## 参照した上流の説明

- [固定コミットのREADME](https://github.com/RawTherapee/RawTherapee/blob/1924179107995b01b73cdc7f4fe91e44fc8227a7/README.md)はプログラムをGPLv3と説明しています。データごとの著作権表示も保持します。
- [RawPediaのDCP作成手順](https://rawpedia.pixls.us/how_to_create_dcp_color_profiles/)にはCC0表記を付ける作成例があります。この作成例を、過去の全プロファイルへの許諾としては扱っていません。
- [上流Issue #9](https://github.com/RawTherapee/RawTherapee/issues/9#issuecomment-129866721)には、2010年当時のプロファイルをGPLと考える旨の回答があります。後年追加されたICC・ICM・DCPの全ファイルに対する明示確認ではなく、処理プリセットとの区別も明確でないため、141件の確認を一括で完了する根拠にはしていません。

確認対象のプロファイルを削除・交換すると現像結果が変わる可能性があります。今回の整理ではアプリ内のデータを変更していません。上流への照会は行っておらず、適用ライセンスと必要な表示が明確でないものは未確認として記録を残しています。
