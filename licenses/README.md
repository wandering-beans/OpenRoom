# 第三者ライセンス

macOS版（Apple Silicon）の依存パッケージの名称、バージョン、ライセンス本文の場所は[ライセンス一覧](manifest.json)で確認できます。ビルド用・テスト用のパッケージも含みます。カメラデータとカラープロファイルの著作権表示は[データの一覧](profile-notices.json)をご覧ください。

依存ソースの取得元とハッシュは[ソース一覧](source-archives.json)に記載しています。[対応するリリース](https://github.com/wandering-beans/OpenRoom/releases/tag/v0.7.18)からソース一式をダウンロードできます。
