# OpenRoom

OpenRoomは写真の整理とRAW現像ができるデスクトップアプリです。原本を元の場所に置いたまま編集し、仕上がった写真を別のファイルに書き出せます。

## インストールと更新

[最新版のダウンロード](https://github.com/wandering-beans/OpenRoom/releases/latest)

| 環境 | インストール | 更新 |
| --- | --- | --- |
| Windows 11（x64） | インストーラー（`.exe`）を実行 | 「環境設定」→「更新を確認」→「更新して再起動」 |
| macOS 26以降（Apple Silicon） | macOS版のZIPを展開 | OpenRoomを終了し、最新版のZIPから展開したアプリで置き換える |

## 写真を開いて書き出す

1. 初回起動時に[利用規約](TERMS.md)と[免責事項](DISCLAIMER.md)を読み、「同意して続ける」を選びます。
2. カタログを作成するか、既存のカタログを開きます。左の「フォルダー」の「＋」で写真が入ったフォルダを追加します。
3. ライブラリで写真を選び、「現像」で明るさや色を調整します。現像設定は自動保存されます。タグとメモは手動で保存してください。
4. 写真を右クリックし、「書き出し」で形式（JPEG・PNG・TIFF）と保存先を選びます。元の写真のEXIF・GPS情報は書き出した画像に含まれません。

RAW、JPEG、HEIF、PNG、TIFF、AVIF、PSD、PSBを読み込めます。入力上限は1枚につき6,400万画素・1 GiBです。RAWはカメラや圧縮方式によって対応が異なります。

## バックアップ

左の「カタログを管理」→「コピーを保存」で、評価や現像設定を含むカタログとプレビューをバックアップできます。写真原本は別途バックアップしてください。
