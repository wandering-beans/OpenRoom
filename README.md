# OpenRoom

OpenRoomは写真の整理とRAW現像ができるデスクトップアプリです。原本を元の場所に置いたまま編集し、仕上がった写真を別のファイルに書き出せます。

## インストールと更新

### macOS 26以降（Apple Silicon）

1. 最新リリースの「Assets」から、ファイル名の末尾が `-macos-arm64.dmg` のファイルをダウンロードし、ダブルクリックします。[最新版のダウンロード](https://github.com/wandering-beans/OpenRoom/releases/latest)
2. 開いたウインドウで、`OpenRoom` を隣の `Applications` フォルダにドラッグします。旧版から更新するときは、先にOpenRoomを終了し、確認画面で「置き換える」を選びます。
3. コピーが終わったらディスクイメージを取り出し、Finderの「アプリケーション」からOpenRoomを開きます。

公開中のMac版はAppleのDeveloper ID署名と公証を受けていないため、初回起動時にmacOSが警告を表示することがあります。[警告が表示されたときのAppleの案内](https://support.apple.com/ja-jp/102445)

### Windows 11（x64）

最新版のリリースからWindows用インストーラー（`.exe`）をダウンロードして実行します。インストール済みの場合は「環境設定」→「更新を確認」→「更新して再起動」で更新できます。[最新版のダウンロード](https://github.com/wandering-beans/OpenRoom/releases/latest)

## 写真を開いて書き出す

1. 初回起動時に[利用規約](TERMS.md)と[免責事項](DISCLAIMER.md)を読み、「同意して続ける」を選びます。
2. カタログを作成するか、既存のカタログを開きます。左の「フォルダー」の「＋」で写真が入ったフォルダを追加します。
3. ライブラリで写真を選び、「現像」で明るさや色を調整します。現像設定は自動保存されます。タグとメモは手動で保存してください。
4. 写真を右クリックし、「書き出し」で形式（JPEG・PNG・TIFF）と保存先を選びます。元の写真のEXIF・GPS情報は書き出した画像に含まれません。

RAW、JPEG、HEIF、PNG、TIFF、AVIF、PSD、PSBを読み込めます。入力上限は1枚につき6,400万画素・1 GiBです。RAWはカメラや圧縮方式によって対応が異なります。

写真を右クリックして「ディスクから削除…」→「ゴミ箱に移動」を選ぶと、原本がゴミ箱に移り、プレビューや編集履歴もカタログから消えます。フォルダーを右クリックした場合は、サブフォルダーを含め、そのカタログに登録した写真が対象です。原本を残して登録だけを外す場合は「カタログから削除…」を選んでください。

## バックアップ

左の「カタログを管理」→「コピーを保存」で、評価や現像設定を含むカタログとプレビューをバックアップできます。写真原本は別途バックアップしてください。
