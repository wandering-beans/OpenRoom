# OpenRoom

OpenRoomは、写真の整理・選別・RAW現像を行うデスクトップアプリです。写真を元の保存場所に置いたまま管理し、原本を書き換えずに編集できます。日本語と英語に対応しています。

## はじめに

現在のmacOSビルドはApple Silicon・macOS 27以降向けです。開発中のアプリで、公開配布用の署名・公証は行っていません。Windows/Linuxでのアプリ起動は未確認です。ソースから起動する場合は[ビルド手順](DEVELOPMENT.md)を参照してください。

1. 写真の入ったフォルダを追加します。原本をコピーせず、一覧表示用のプレビューを作成します。
2. ライブラリで写真を選び、星評価・フラグ・カラーラベルで整理します。撮影日やカメラ、レンズなどでも絞り込めます。
3. 現像画面で明るさや色、切り抜きなどを調整します。現像設定は自動保存されます。
4. 写真を右クリックして「書き出し」を選び、編集結果を別の画像として保存します。

## 写真の整理と比較

グリッドで一覧、ルーペで1枚ずつ表示できます。比較表示では2枚を並べ、基準の写真を固定したまま候補を切り替えます。選別表示は複数の候補を並べて絞り込むための画面です。「候補から外す」や除外フラグで原本が削除されることはありません。

テキスト、星評価、フラグ、カラーラベル、撮影情報を組み合わせて検索できます。撮影情報を初めて読み込む際は、処理が終わるまで一部の写真が検索条件に一致しないことがあります。

## 現像

露光量、ホワイトバランス、コントラスト、彩度、トーンカーブ、色別の調整、カラーグレーディング、シャープ、ノイズ低減に対応しています。切り抜き・回転・反転、手動の遠近・歪曲補正、周辺光量、粒子も調整できます。スライダーをダブルクリックすると、その項目を初期値へ戻せます。

ブラシ、線形・円形グラデーション、色域・輝度域を使って部分補正できます。マスクを使う場合は、遠近や歪曲などの幾何変形を先に行ってください。

設定のコピー・貼り付け、複数写真への同期、プリセットの保存に対応しています。変更前との比較や、名前付きスナップショットを使った比較も可能です。

現像設定は操作を止めると自動保存され、「今すぐ保存」でも保存できます。ヒストリーから直近10回の操作を取り消せます。保存された履歴はアプリを再起動しても利用できますが、自動保存前に強制終了した場合の変更は復元できません。タグ・メモは手動保存です。

ライブラリでは長辺最大1,600pxのプレビューを表示します。細部を確認する場合は、現像画面の「原寸表示」を使ってください。原本が未接続でも保存済みプレビューは閲覧できますが、現像と書き出しには原本への接続が必要です。

## 書き出し

ライブラリの写真一覧、またはライブラリ・現像画面のフィルムストリップで写真を選び、右クリックの「書き出し」を開きます。形式、画質、容量制限、保存先、命名規則、長辺のサイズを指定できます。

JPEG、PNG、TIFFに対応し、JPEGの品質は1〜100、PNG/TIFFは16bitで保存します。出力はsRGB・SDRです。原本や同名の既存ファイルは上書きせず、元画像のEXIF・GPS情報は転記しません。

「余白の枠」で白枠・黒枠を選び、枠を含む画像の縦横比を指定できます。写真を切り抜かず中央に配置し、四辺に余白を加えます。長辺のサイズ指定は枠を含む画像全体に適用されます。

## カタログとバックアップ

写真の参照先、評価、タグ、メモ、現像設定、編集履歴はカタログに保存します。原本は元の場所に残ります。カタログとプレビューをローカルSSDに置き、原本をNASに保管する使い方にも対応しています。

左パネルの「カタログを管理」から、カタログの新規作成、切り替え、保存場所の表示、コピー保存ができます。バックアップには「カタログのコピーを保存…」を使用してください。

コピーには`.openroom`ファイルと対応する`.previews`フォルダが含まれます。写真原本は含まれないため、別途バックアップが必要です。手動でカタログを移動する場合も、カタログと`.previews`フォルダを一緒に移動してください。

## 対応形式と制限

| 分類 | 拡張子 |
| --- | --- |
| RAW | dng, cr2, cr3, crw, arw, sr2, srf, raf, nef, nrw, rw2, orf, pef, rwl, srw, 3fr, fff, iiq |
| JPEG | jpg, jpeg |
| HEIF | heic, heif, hif |
| その他の写真形式 | png, tif, tiff, avif |
| Photoshop | psd, psb |

入力上限は64MP・1GiBです。RAWは同じ拡張子でも、カメラや圧縮方式によって読み込めない場合があります。カメラのJPEGと色や階調が完全に一致するわけではありません。

TIFFは先頭画像、PSD/PSBは保存済みの合成画像を表示します。レイヤー編集、HDR表示・書き出し、Lightroomカタログの取り込みには対応していません。PDF・SVG・GIF・BMP・WebP・HDR/EXR、SigmaのX3F、旧型Panasonic／Leicaの拡張子RAWも対象外です。

## 主なショートカット

macOSではCmd、Windows/LinuxではCtrlを使用します。

| キー | 操作 |
| --- | --- |
| G / E | グリッド / ルーペ表示 |
| C / N | 比較 / 選別表示 |
| D | 現像画面を開く |
| Space | グリッドとルーペを切り替える |
| ← / → | 前後の写真を選ぶ |
| 0〜5 | 星評価を設定する（0は未評価） |
| P / X / U | 採用 / 除外 / フラグ解除 |
| Cmd+F / Ctrl+F | 検索欄を開く |
| Cmd+S / Ctrl+S | 現像設定を今すぐ保存する |
| Cmd+Z / Ctrl+Z | 変更を取り消す |

## AI連携

環境設定でAI連携を有効にすると、同じPCの対応AIアプリから写真の検索・整理・現像・書き出しを操作できます。初期状態は無効です。接続したAIは、カタログの更新や書き出しを確認なしで実行できるため、信頼するクライアントだけを接続してください。

接続方法と操作の詳細は[AI連携ガイド](MCP.md)、依存ライブラリのライセンスは[THIRD_PARTY.md](THIRD_PARTY.md)を参照してください。
