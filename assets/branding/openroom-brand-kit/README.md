# OpenRoom ブランド素材

採用した「Orと分光」のロゴを基に、アプリで使う素材をまとめました。
[素材一覧](index.html)をブラウザで開くと、ロゴ、アイコンの実寸、起動画面を確認できます。

## 使い方

通常のアプリアイコンにはPNG・ICNS・ICOを使います。PNGとICNS・ICO内の画像は、採用した原本のサイズを書き出したものです。角丸の外側は透過しています。

macOS 27では、アプリの`Contents/Resources/`に`icons/macos/Assets.car`も配置し、Info.plistの`CFBundleIconName`を`AppIcon`に設定します。実アプリのAbout画面で、従来の白い外枠がなくなることを確認しています。

横組みロゴは黒背景を含むPNGです。白背景で使う場合は、黒いロゴ領域を保って配置してください。完全なベクター版は含みません。

起動画面のPNGには、起動状態やバージョンを焼き込んでいません。アプリ側で必要な表示を重ねられます。HTMLには読み込み中の表示例を含めました。実際の起動処理との連動は実装していません。動きを減らす設定では、読み込み表示のアニメーションを停止します。

原本の「Or」と分光の配置を保ちます。色は黒と白を基本とし、分光色はロゴの光に使います。個別の文字の足元に光を集中させず、文字全体の背後に広げる構成です。

CSSの色は周辺素材を作るための指定値です。ロゴ画像の全ピクセルが、この値だけで構成されるわけではありません。書体はOSのシステム書体を使い、フォントファイルは同梱していません。

## アプリへの組み込み

Tauri設定の表示名をOpenRoomに変更し、`desktop/icons/icon.png`・`icon.icns`・`icon.ico`へ採用アイコンを反映しました。アプリのヘッダーにもロゴと名前を配置し、カタログを読み込む間は同じデザインの起動画面を表示します。実装は`desktop/ui/`にあり、このフォルダのHTMLは素材確認用です。

## 確認範囲

アイコン11サイズの寸法と透過、ICNS・ICOの全収録サイズのデコード、採用原本との一致を確認しました。起動画面は1600 × 1000 pxと3200 × 2000 pxで書き出し、表示を確認しました。素材一覧は幅1200 pxと390 pxで横方向にはみ出さないことを確認しています。

組み込み後のUIテストでは、起動画面の表示・終了、読み込み中の操作抑止、読み込み失敗時の復帰を確認しています。Mac版をビルドし、テスト専用カタログで起動して、ヘッダー、アプリメニュー、About画面の名前とロゴを確認しました。Windows・Linuxでの実機表示は未確認です。
